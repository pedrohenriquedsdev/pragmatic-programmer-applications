## 🇺🇸 English

Practical implementations and experiments based on the concepts from **The Pragmatic Programmer** (by David Thomas and Andrew Hunt), organized by topic and programming language.

### 📖 About

This repository is a hands-on companion to *The Pragmatic Programmer*. Instead of just reading about the principles, each topic here has small, focused examples, exercises, or mini-projects that put a specific concept into practice — from DRY and orthogonality to automation, testing, and design techniques.

The goal is to build intuition through code, not just theory.

### 🗂️ Structure

The repository is organized by **topic**, and within each topic, by **programming language**:

```
pragmatic-programmer-applications/
├── topic-name/
│   ├── language-1/
│   │   └── example implementation
│   └── language-2/
│       └── example implementation
├── another-topic/
│   └── ...
└── README.md
```

Each topic folder generally includes:
- A short explanation of the concept
- One or more practical examples/exercises
- Notes on trade-offs or when to apply (or not apply) the idea

### 🧩 Topics Covered (examples)

- **DRY (Don't Repeat Yourself)**
- **Orthogonality**
- **Reversibility**
- **Tracer Bullets & Prototyping**
- **Domain Languages**
- **Estimating**
- **Refactoring**
- **Testing (Design by Contract, Assertive Programming)**
- **Decoupling**
- **Automation**
- **Property-Based Testing**

*(This list grows as new topics are added.)*

### 🚀 Getting Started

1. Navigate to the topic and language folder you're interested in
2. Check for a local `README.md` with specific instructions (if present)
3. Follow the language-specific setup (dependencies, build steps, etc.)

### 🤝 Contributing

Contributions are welcome! Feel free to open an issue or a pull request to add a new example, a new language implementation, or a new topic from the book.

## 🇧🇷 Português

Implementações práticas e experimentos baseados nos conceitos do livro **The Pragmatic Programmer** (David Thomas e Andrew Hunt), organizados por tópico e linguagem de programação.

### 📖 Sobre

Este repositório é um complemento prático ao livro *The Pragmatic Programmer*. Em vez de apenas ler sobre os princípios, cada tópico aqui conta com exemplos, exercícios ou mini-projetos focados que colocam um conceito específico em prática — desde DRY e ortogonalidade até automação, testes e técnicas de design.

O objetivo é construir intuição através de código, não apenas teoria.

### 🗂️ Estrutura

O repositório está organizado por **tópico** e, dentro de cada tópico, por **linguagem de programação**:

```
pragmatic-programmer-applications/
├── nome-do-topico/
│   ├── linguagem-1/
│   │   └── implementação de exemplo
│   └── linguagem-2/
│       └── implementação de exemplo
├── outro-topico/
│   └── ...
└── README.md
```

Cada pasta de tópico geralmente inclui:
- Uma breve explicação do conceito
- Um ou mais exemplos/exercícios práticos
- Notas sobre trade-offs ou quando aplicar (ou não) a ideia

### 🧩 Tópicos Abordados (exemplos)

- **DRY (Don't Repeat Yourself)**
- **Ortogonalidade**
- **Reversibilidade**
- **Tracer Bullets & Prototipação**
- **Linguagens de Domínio**
- **Estimativas**
- **Refatoração**
- **Testes (Design by Contract, Programação Assertiva)**
- **Desacoplamento**
- **Automação**
- **Testes Baseados em Propriedades (Property-Based Testing)**

*(Essa lista cresce conforme novos tópicos são adicionados.)*

### 🚀 Como Começar

1. Navegue até a pasta do tópico e da linguagem que te interessa
2. Verifique se há um `README.md` local com instruções específicas (se existir)
3. Siga a configuração específica da linguagem (dependências, build, etc.)
